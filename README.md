# E-commerce Core (Основы ООП)

Проект реализует базовые сущности для платформы электронной коммерции: товары и категории товаров.

## Реализованный функционал
* **Класс `Product`**: описывает товар со свойствами `name` (название), `description` (описание), `price` (цена) и `quantity` (количество в наличии).
* **Класс `Category`**: описывает категорию со свойствами `name` (название), `description` (описание) и `products` (список товаров).
* **Автоматический подсчет**: в классе `Category` реализованы атрибуты класса `category_count` и `product_count`, которые автоматически обновляются при инициализации новой категории.
* **Тестирование**: написаны юнит-тесты с использованием `pytest` и фикстур, проверяющие инициализацию объектов и корректность работы счетчиков.

## Запуск проекта и тестов
1. Установите зависимости:
   ```bash
   poetry install
   ```
2. Запустите демонстрационный скрипт:
   ```bash
   poetry run python main.py
   ```
3. Запустите тесты с проверкой покрытия:
   ```bash
   poetry run pytest --cov=src --cov-report=html
   ```
